# Security policy

## Reporting a vulnerability

Email hello@vmarea.com with the details. Please do not open a public issue for a security problem.

Include the script and version affected, what you observed and, if you can, the steps to reproduce it. We will acknowledge your report and keep you informed until it is resolved.

## Scope

In scope: the scripts in this repository, including how they download, verify, configure and start software, and how they generate, store and print credentials.

Out of scope: vulnerabilities in the upstream apps themselves. Report those to the app's own project. If a pinned version here has a known upstream fix, tell us and we will bump the pin.

## Supported versions

Only the latest commit on the default branch is supported.
